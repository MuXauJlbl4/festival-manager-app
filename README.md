# Менеджер Фестивалей

Информационная система для автоматизации организации и проведения фестивалей. Веб-приложение для лабораторной работы по Java/Spring.

## Описание

Система представляет собой веб-сайт и панель управления для работы с различными аспектами фестиваля: от создания самого фестиваля и его площадок до управления расписанием мероприятий и назначения участников.

Приложение имеет публичную часть (главную страницу), где любой посетитель может ознакомиться со списком фестивалей и мероприятий, и защищенную панель управления с доступом по ролям.

## Ключевые возможности

- **Публичный сайт**: Главная страница с обзором ближайших фестивалей и популярных мероприятий.
- **Панель управления (SPA)**: Полноценное одностраничное приложение на чистом JavaScript для управления данными.
- **Управление сущностями**: CRUD-операции (создание, чтение, обновление, удаление) для всех ключевых данных:
    - Фестивали
    - Площадки и помещения
    - Типы мероприятий и сами мероприятия
    - Участники и их типы
- **Ролевая модель доступа**:
    - **Администратор**: Полный доступ ко всей системе, включая управление пользователями и ролями.
    - **Организатор**: Управление структурой фестиваля (фестивали, площадки, мероприятия).
    - **Менеджер**: Управление конкретными мероприятиями и их участниками.
    - **Пользователь**: Только просмотр расписания и основной информации.
- **Бизнес-логика**: Реализованы проверки, такие как невозможность провести два мероприятия в одном помещении в одно время или назначить одного артиста на пересекающиеся по времени выступления.
- **Безопасность**: Аутентификация на основе JWT (JSON Web Token).

## Технологический стек

### Backend
- **Java 25**
- **Spring Boot 4.
- **Spring Web**, **Spring Data JPA**, **Spring Security**
- **Liquibase** для миграций базы данных
- **SQL База данных**: H2 (встроенная, для быстрого старта) и поддержка PostgreSQL (для production)
- **Spring Boot Actuator** для мониторинга

### Frontend
- **HTML5**
- **CSS3** (Flexbox, Grid)
- **JavaScript (ES6+)**

### Сборка и тестирование
- **Maven**
- **JUnit 5** и **Mockito** для тестов
- **JaCoCo** для отчетов о покрытии кода тестами.

## Запуск приложения

1.  **Убедитесь, что у вас установлены:**
    - **Java (JDK) версии 25**.
    - **Apache Maven**.

2.  **Настройка `JAVA_HOME`**:
    Перед запуском необходимо, чтобы переменная окружения `JAVA_HOME` указывала на директорию с установленным JDK 25.

3.  **Запуск команды**:
    В корневой директории проекта выполните команду в терминале:
    ```bash
    mvn spring-boot:run
    ```

4.  **Откройте приложение в браузере**:
    После успешного запуска приложение будет доступно по адресу:
    [http://localhost:8080](http://localhost:8080)

## Тестовые пользователи

Для входа в панель управления можно использовать следующих тестовых пользователей (логин / пароль):

-   `admin` / `admin` (Администратор)
-   `organizer` / `organizer` (Организатор)
-   `manager` / `manager` (Менеджер)
-   `user` / `user` (Пользователь)

## Основные эндпоинты API

Все эндпоинты находятся по префиксу `/api`.

-   **Аутентификация**: `POST /auth/login`
-   **Фестивали**: `GET, POST, PUT, DELETE /festivals`
-   **Мероприятия**: `GET, POST, PUT, DELETE /events`
-   **Пользователи**: `GET, POST, PUT, DELETE /users`
-   **Роли**: `GET, POST, PUT, DELETE /roles`
-   ... и другие, соответствующие всем сущностям системы.
